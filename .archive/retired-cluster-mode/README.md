# Retired active/passive cluster mode

This directory preserves the pre-v0.1 active/passive implementation removed by
ADR 0008. It is archive material, is outside the Go module, and is not built,
configured, or supported by DockerCD v0.1. Do not restore it piecemeal; any
future HA work requires a new ADR with fencing, replication, recovery, and
failure-drill evidence.
