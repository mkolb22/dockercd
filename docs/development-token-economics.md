# DockerCD development cost and attention

Status: a measurement framework, not a cost-saving claim. Adapted on
2026-10-04 from `bodhi-ai` commit `ca7d286a712441250dff6cda75bcb97e03e37719`,
`docs/development-token-economics.md`; DockerCD has no project-local
provider-usage ledger or measured workflow ROI.

Optimize for accepted, durable outcomes while preserving mandatory safety and
quality gates. Keep subscription capacity, API usage, local compute, elapsed
time, repair/review effort, and owner attention separate. Missing usage is
unknown, not zero, and parallel work may shorten elapsed time while increasing
total consumption.

For a future comparable set of tranches, record baseline/candidate identity,
research and review effort, retries, validation, maintenance, defects, and
owner interruptions. Include failed attempts. Do not infer dollar savings from
model names, percentages, or a single project packet; never weaken independent
review or deployment safeguards to make an experiment appear cheaper.
